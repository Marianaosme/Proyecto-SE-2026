## Descripción General Del Sistema
El sistema está compuesto por dos módulos principales: un guante de captura de movimiento y una mano robótica actuada mediante servomotores. El guante incorpora potenciómetros para detectar la flexión de los dedos y un giroscopio para medir la orientación de la muñeca. Estas señales son adquiridas y procesadas por un sistema embebido encargado de interpretar los movimientos realizados por el usuario. El guante envía la información a través de la frecuencia de 2.4GHz usando en protocolo ESP-NOW. 

Debido a que el guante fue diseñado para la mano derecha y la mano robótica corresponde a una configuración de mano izquierda, los movimientos se replican en espejo. A demás, cuanta con una pantalla OLED 0.96 que permite visualizar la flexión actual de cada uno de los dedos y el estado de la conexión inalámbrica con la mano robótica. Cuanta con un botón lateral encargado de activar el protocolo de calibración en donde el usuario recibirá instrucciones en la pantalla del guante para realizar la recalibración exitosa de este.

## Componentes Del Sistema 
A continuación, se presentan los componentes utilizados para la implementación y funcionamiento del sistema, incluyendo elementos mecánicos, electrónicos y de alimentación.

- Estructura mecánica

| Componente | Observación |
|------------|-------------|
| Mano robótica impresa en 3D | Estructura principal del sistema, diseñada para simular la anatomía de una mano humana. Cuenta con un sistema de tendones accionados por servomotores que permiten la flexión y extensión de cada dedo. Las articulaciones están ensambladas mediante tornillos M3, tuercas y elementos como alambres para la transmisión del movimiento. |
| Guante de control | Estructura diseñada para controlar la mano robótica usando un guante con piezas personalizadas impresas en 3D y potenciómetros para determinar la flexión de cada dedo y enviar esos datos al ESP32 para su posterior procesamiento. |

- Sistema de control 

| Componente | Observación |
|------------|-------------|
| 2 ESP 32 | Microcontrolador encargado de procesar las señales de entrada y controlar el movimiento de los servomotores. |

- Actuadores

| Componente | Observación |
|------------|-------------|
| 5 Servomotores SG90 | Utilizados para el movimiento individual de cada dedo de la mano. |
| 1 Servomotor MG995 | Encargado de la rotación de la muñeca, proporcionando un mayor torque en comparación con los servomotores de los dedos. |

- Sensores 

| Componente | Observación |
|------------|-------------|
| Giroscopio MPU6050 | Sensor utilizado para detectar la rotación en el plano XY, permitiendo generar señales de control para la mano robótica. |
| 5 Potenciómetros 10K | Usados como sensores para determinar la flexión de cada dedo. |

- Sistema electrónico y conexión

| Componente | Observación |
|------------|-------------|
| 3 PCB universal | Permite organizar y conectar de manera estable los componentes electrónicos del sistema. |
| Cables y cables jumper | Utilizados para realizar las conexiones entre los diferentes componentes del sistema. |
| 3 Botones Push | Accionadores para los diferentes modos de operación del sistema. |

- Sistema de alimentación

| Componente | Observación |
|------------|-------------|
| Fuente de alimentación (12V – 5A) | Proporciona la energía necesaria para el funcionamiento del sistema, especialmente para los servomotores que demandan alta corriente. |
| Cable de alimentación | Permite la conexión de la fuente de energía al sistema. |
| Capacitor cerámico | Utilizado para filtrar el ruido en la alimentación del ESP32, mejorando la estabilidad del sistema. |
| Fuente reguladora de voltaje (3.3V y 5V) | Reduce el voltaje a un nivel seguro para los componentes más sensibles. |
