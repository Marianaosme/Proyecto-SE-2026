## Introducción  

Los sistemas embebidos son sistemas electrónicos diseñados para realizar funciones específicas dentro de un dispositivo más grande, integrando componentes de hardware y software que permiten ejecutar tareas de manera eficiente y automatizada. Estos sistemas se encuentran presentes en múltiples aplicaciones tecnológicas, como dispositivos médicos, sistemas de automatización industrial, vehículos inteligentes y equipos robóticos.  

En el campo de la robótica, los sistemas embebidos desempeñan un papel fundamental, ya que permiten procesar la información proveniente de sensores y generar señales de control para actuadores, haciendo posible la interacción entre el entorno y el sistema robótico.


## Problema

En este proyecto se propone el desarrollo de un sistema de control para una mano robótica manejada de forma remota. Para el desarrollo del prototipo, el sistema de control estará conectado directamente a la mano robótica usando el protocolo ESP-NOW, con el fin de facilitar la transmisión de señales en tiempo real y simplificar el control del sistema. 

Para lograr el control de la mano robótica, se emplearán potenciómetros como sensores para detectar la flexión de cada uno de los dedos de la mano, así como un giroscopio para medir la rotación de la muñeca. La información capturada por estos sensores será procesada por un microcontrolador ESP32, encargado de capturar las señales, procesarlas e interpretarlas para finalmente ser enviadas a la mano robótica, donde esta tomará los comandos obtenidos para interpretarlos en movimientos. 

De esta manera, el proyecto busca demostrar cómo los sistemas embebidos pueden integrarse con sensores y elementos de control, permitiendo desarrollar soluciones tecnológicas capaces de reproducir de manera análoga mecanismos del cuerpo humano y que, como proyección futura, puedan facilitar la manipulación remota de objetos. 


## Alcance

El proyecto contempla el diseño e implementación de un prototipo funcional de una mano robótica controlada mediante un guante de captura de movimiento. El sistema será capaz de detectar la flexión y extensión de los dedos, así como la rotación de la muñeca, para reproducir dichos movimientos en la mano robótica en espejo. 

El alcance incluye: 
- Diseño e integración del sistema electrónico y embebido.  
- Implementación de sensores para captura de movimiento.  
- Procesamiento de señales y control de actuadores.  
- Desarrollo de la estructura básica de la mano robótica.  
- Comunicación remota entre el controlador y el actuador. 
- Realización de pruebas funcionales del sistema. 


## Objetivos
### Objetivo  General 
Diseñar un sistema de control para una mano robótica, capaz de replicar en espejo ciertos movimientos de la mano humana, como la flexión y extensión de los dedos, y la rotación de la muñeca, mediante el uso de un guante de control.   

### Objetivos Específicos
- Diseñar la estructura mecánica de la mano robótica que permita la flexión y extensión de los dedos, la rotación de la muñeca y la posible manipulación de diferentes objetos. 

- Desarrollar un sistema de control y comunicación que permita enviar y recibir señales para el manejo remoto de la mano. 

- Replicar movimientos precisos y correctos capturados por el sistema.
