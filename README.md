Los sistemas embebidos son sistemas electrónicos diseñados para realizar funciones específicas dentro de un dispositivo más grande, integrando hardware y software para ejecutar tareas de manera eficiente. Estos sistemas se encuentran presentes en múltiples aplicaciones tecnológicas como dispositivos médicos, sistemas de automatización industrial, vehículos inteligentes y equipos robóticos. 

En el campo de la robótica, los sistemas embebidos cumplen un papel fundamental, ya que permiten procesar información proveniente de sensores y generar señales de control para actuadores, haciendo posible la interacción entre el entorno y el sistema robótico.
